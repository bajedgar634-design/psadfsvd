# Учёт личных финансов

Консольное приложение на Python для учёта доходов и расходов. Данные хранятся в базе данных SQLite.

## Описание

Программа помогает вести личный бюджет: записывать доходы и расходы, разбивать их по категориям, смотреть баланс и анализировать, на что уходит больше всего денег. Всё работает на стандартной библиотеке Python — никаких внешних зависимостей.

## Возможности

- Добавление доходов и расходов с датой, категорией и комментарием
- Просмотр всех операций в виде таблицы
- Статистика: общий доход, расход, баланс, доля расходов по категориям с текстовой диаграммой и разбивкой по месяцам
- Удаление операций по ID
- Экспорт данных в CSV с меткой времени (не перезаписывает предыдущие выгрузки)
- Проверка вводимых данных: сумма (в т.ч. `nan`/`inf`), дата, категория, тип операции
- Поддержка относительных дат: `Enter` — сегодня, `-N` — N дней назад

## Технологии

- Python 3.9+
- `sqlite3` — база данных
- `csv` — экспорт данных
- `datetime` — работа с датами
- `contextlib`, `pathlib`, `typing` — вспомогательные модули стандартной библиотеки

Внешние библиотеки не нужны.

## Запуск

```bash
python finance_tracker.py
```

При первом запуске автоматически создаётся файл базы данных `finance.db`.

## Пример работы

```
===== УЧЁТ ФИНАНСОВ =====
1. Добавить операцию
2. Показать все операции
3. Статистика
4. Удалить операцию
5. Экспорт в CSV
0. Выход
```

Пример ввода новой операции:

```
--- Новая операция ---
Тип (1 - доход, 2 - расход): 2
Дата (ГГГГ-ММ-ДД, Enter = сегодня, -1 = вчера): -1
  1. Еда
  2. Транспорт
  ...
Номер категории: 1
Сумма: 1200
Комментарий (необязательно): продукты
Операция добавлена!
```

Пример статистики:

```
--- Статистика ---
Доходы:    50000.00
Расходы:    1500.00
Баланс:    48500.00

Расходы по категориям:
  Еда            1200.00  80.0% ██████████████████████████████
  Транспорт       300.00  20.0% ███████

Доходы/расходы по месяцам:
  2026-10:  +50000.00   -1500.00  = 48500.00
```

> Длина полосы диаграммы нормируется на самую крупную категорию (30 символов) — так пропорции видны даже при маленьких суммах.

## Структура базы данных

Таблица `records`:

| Поле     | Тип     | Описание                       |
|----------|---------|--------------------------------|
| id       | INTEGER | Уникальный номер записи        |
| date     | TEXT    | Дата операции (ГГГГ-ММ-ДД)     |
| kind     | TEXT    | Тип: «доход» или «расход»      |
| category | TEXT    | Категория операции             |
| amount   | REAL    | Сумма (больше нуля)            |
| note     | TEXT    | Комментарий                    |

Индекс `idx_records_date` ускоряет сортировку и фильтрацию по дате.

## Основные функции

| Функция            | Назначение                                                       |
|--------------------|------------------------------------------------------------------|
| `get_connection()` | Контекстный менеджер: commit при успехе, rollback при ошибке     |
| `init_db()`        | Создаёт таблицу и индекс                                         |
| `add_record()`     | Добавляет операцию                                               |
| `get_records()`    | Возвращает все операции                                          |
| `delete_record()`  | Удаляет операцию по ID                                           |
| `input_amount()`   | Безопасный ввод суммы (отсекает `nan`, `inf`, нечисла)           |
| `input_date()`     | Ввод даты с поддержкой `Enter` и `-N`                            |
| `choose_kind()`    | Ввод типа операции (только `1` или `2`)                          |
| `menu_add()`       | Пункт меню «Добавить операцию»                                   |
| `menu_list()`      | Пункт меню «Показать все операции»                               |
| `menu_stats()`     | Считает и выводит статистику, диаграмму и разбивку по месяцам    |
| `menu_delete()`    | Пункт меню «Удалить операцию»                                    |
| `menu_export()`    | Выгружает данные в CSV с меткой времени                          |
